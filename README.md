# Dhorbook 📖
A premium Quran dhor (revision) tracker for Huffaath.

## Features
- **Daily Notifications**: Set your time for a daily dhor reminder.
- **Log Dhor**: Track your "looking-in" reading progress.
- **Testing Mode**: Record mistakes and track memory retention.
- **Analytics**: View line graphs of your progress and weakest Juz.
- **Theme**: Oxford Blue & Metallic Gold aesthetic.
